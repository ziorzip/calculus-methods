다섯 수학자의 미분법

곡선 y = x²의 접선의 기울기를 구하는 과정 비교

1. 페르마

y = x²에서 x = 2, E = 1로 그린 예. 주황 직선 PP′은 E를 줄이면 초록 접선에 가까워진다. (a = TQ, b = PQ, QQ′ = E)

계산 과정

  1. P(x, x²), P′(x+E, (x+E)²)
    곡선 위의 점 P와, P에서 오른쪽으로 아주 작은 양 E만큼 떨어진 점 P′을 잡는다. 수선의 발을 Q, Q′라 하고 TQ = a, PQ = b라 한다.
  2. 직선 PP′의 기울기 = b/a
    직각삼각형 TQP에서 기울기는 세로 ÷ 가로이다.
  3. b/a = (x+E)² / (a+E)
    삼각형 TQP와 TQ′P′은 닮음이다. Q′P′ = (x+E)², TQ′ = a + E이므로 같은 비를 쓸 수 있다.
  4. b(a+E) = a(x+E)² = a(x² + 2xE + E²)
    양변에 a(a+E)를 곱해 분모를 없애고, (x+E)²을 전개한다.
  5. bE = 2axE + aE²
    P의 y좌표가 x²이므로 b = x²이다. 그러면 ba와 ax²이 서로 지워진다.
  6. b = 2ax + aE
    E는 0이 아니므로 양변을 E로 나눌 수 있다.
  7. b/a = 2x + E
    양변을 a로 나누면 직선 PP′의 기울기가 나온다.
  8. E를 0으로 간주 → b/a = 2x
    E는 얼마든지 작아질 수 있으므로 마지막에 0으로 본다. P′이 P에 가까워져 직선 PP′은 접선이 되고, 접선의 기울기는 2x이다.
  9. x = 2일 때 b/a = 5 → 4.5 → 4.1 → 4
    E = 1, 0.5, 0.1일 때 2x + E 값이 E = 0일 때의 4(= 2x)에 가까워진다.

2. 데카르트

x = 1일 때: 중심 C(3, 0)인 원이 P(1, 1)에서 곡선에 접한다. 교점이 둘에서 하나(중근)로 겹치는 순간이 접하는 순간이다.

계산 과정

  1. 원 (X−v)² + Y² = r²
    접선을 구하려는 점 P(1, 1)를 지나고 중심 C(v, 0)이 x축 위에 있는 원을 생각한다. 이 원이 P에서 곡선과 접하면, 원의 접선이 곡선의 접선이 된다.
  2. X⁴ + X² − 2vX + v² − r² = 0
    곡선 Y = X²을 원의 방정식에 대입한다. (X−v)² = X² − 2vX + v²이다. 이 방정식의 해가 원과 곡선이 만나는 점의 x좌표이다.
  3. (X−1)²(X² + pX + q) = 0 꼴
    원이 P에서 접하면 두 교점이 P에서 하나로 겹친다. 즉 X = 1이 중근이므로 (X−1)²로 인수분해된다.
  4. X⁴ + (p−2)X³ + (q−2p+1)X² + (p−2q)X + q
    (X−1)²(X² + pX + q)를 전개한 식이다.
  5. p = 2, q = 4, v = 3, r² = 5
    앞의 방정식과 계수를 비교한다. X³: p−2 = 0, X²: q−2p+1 = 1, X: p−2q = −2v, 상수항: q = v²−r². 차례로 풀면 p = 2, q = 4, v = 3, r² = 5이다.
  6. 중심 C(3, 0), 반지름² = 5
    곡선에 P(1, 1)에서 접하는 원이 정해졌다.
  7. CP의 기울기 = (1−0)/(1−3) = −1/2
    반지름 CP는 접선에 수직인 법선이다.
  8. 접선의 기울기 = −1/(−1/2) = 2
    수직인 두 직선의 기울기의 곱은 −1이다. x = 1에서 2x = 2와 같다.

3. 배로

y = x²의 점 M에서 e = 0.8로 그린 개념도. 선분 MN을 빗변으로 하는 삼각형이 미분(특성)삼각형이다. 길이 비율은 정확하지 않다.

계산 과정

  1. M(x, y), N(x−e, y−a)
    접선을 구하려는 점 M과, M의 안쪽에 아주 가까운 점 N을 잡는다. e와 a는 줄어든 선분의 길이이다.
  2. 접선의 기울기 ≈ a/e
    선분 MN을 빗변으로 하는 직각삼각형(미분삼각형)의 세로 a, 가로 e이다. N이 M에 아주 가까우면 MN은 접선과 거의 겹친다.
  3. y − a = (x − e)²
    N도 곡선 y = x² 위의 점이므로 N의 좌표를 식에 넣는다.
  4. y − a = x² − 2xe + e²
    (x − e)²을 전개한다.
  5. −a = −2xe + e²
    M도 곡선 위의 점이라 y = x²이다. 양변에서 y와 x²이 서로 지워진다.
  6. a = 2xe − e²
    양변에 −1을 곱한다.
  7. a = 2xe
    e²처럼 e가 두 번 이상 곱해진 항은 너무 작아 버린다.
  8. a/e = 2x
    양변을 e로 나누면 접선의 기울기가 나온다.
  9. x = 3일 때 a/e = 5.2 → 5.6 → 5.9
    e = 0.8, 0.4, 0.1일 때 a/e = 6 − e 값이 2x = 6에 가까워진다.

4. 뉴턴

시간 o 동안 점이 P에서 이동한다. 가로 변화 ẋo, 세로 변화 ẏo. 점선 접선과의 작은 차이가 ẋ²o²이며, o를 0으로 보면 사라진다.

계산 과정

  1. x, y는 시간에 따라 변하는 양, 속도는 ẋ, ẏ
    뉴턴은 곡선을 시간에 따라 움직이는 점의 자취로 보았다. 점이 움직이는 가로 속도를 ẋ, 세로 속도를 ẏ라 한다.
  2. x → x + ẋo, y → y + ẏo
    아주 짧은 시간 o가 지나면 위치가 속도 × 시간만큼 변한다.
  3. y + ẏo = (x + ẋo)²
    움직인 점도 곡선 y = x² 위에 있다.
  4. y + ẏo = x² + 2xẋo + ẋ²o²
    (x + ẋo)²을 전개한다.
  5. ẏo = 2xẋo + ẋ²o²
    y = x²이므로 양변에서 y와 x²이 지워진다.
  6. ẏ = 2xẋ + ẋ²o
    o는 0이 아니므로 양변을 o로 나눌 수 있다.
  7. o를 0으로 간주 → ẏ = 2xẋ
    o는 아주 짧은 시간이므로 마지막에 0으로 본다. 처음에는 0이 아닌 값으로 다루고 마지막에 0으로 취급하는 모순이 있다.
  8. 접선의 기울기 = ẏ/ẋ = 2x
    접선의 기울기는 두 속도의 비이다.
  9. x = 2, ẋ = 1일 때 ẏ = 4.5 → 4
    o = 0.5이면 ẏ = 4 + 0.5 = 4.5이고, o를 0으로 보면 4(= 2x)가 된다.

5. 라이프니츠

곡선을 점점 확대하면 직선처럼 보이고, 그 위의 아주 작은 삼각형의 변이 dx와 dy이다.

계산 과정

  1. x가 dx만큼 변할 때 y는 dy만큼 변한다
    dx, dy는 변수의 아주 작은 변화량이다.
  2. y + dy = (x + dx)²
    변한 점도 곡선 y = x² 위에 있다.
  3. y + dy = x² + 2x dx + (dx)²
    (x + dx)²을 전개한다.
  4. dy = 2x dx + (dx)²
    y = x²이므로 양변에서 y와 x²이 지워진다.
  5. dy = 2x dx
    (dx)²은 dx보다 훨씬 작아서 버린다. 예를 들어 dx = 0.01이면 (dx)² = 0.0001이다.
  6. dy/dx = 2x
    양변을 dx로 나눈 비가 접선의 기울기이다. 현대 표기로는 f′(x) = 2x이다.
  7. x = 2, dx = 0.01일 때 dy/dx = 4.01
    dy = 4×0.01 + 0.0001 = 0.0401이므로 dy/dx = 4.01이고, 2x = 4에 매우 가깝다.
